
# ☕ Java Programming Practice — Batch 1

## 🟢 Level: Beginner

Welcome to **Java Programming Practice – Batch 1**.

This batch is designed for beginners who are learning Java from the basics.

### 🎯 Goal

By completing this batch, you should understand:

* Variables
* Data types
* Basic operators
* Arithmetic operations
* Taking simple input
* Printing output
* Basic calculations
* Writing a complete Java program

---

# 📌 How to Practice

For every question:

1. Read the problem carefully.
2. Identify the **input**.
3. Identify the **expected output**.
4. Think about the formula or logic.
5. Write the Java program yourself.
6. Test it with the given examples.
7. Try your own test cases.

> ⚠️ Do not copy solutions. Try to solve each problem yourself first.

## 19. Simple Interest

### Problem

Calculate the simple interest using the given principal amount, rate of interest, and time.

### Formula

```text
Simple Interest = (P × R × T) / 100
```

Where:

* `P` = Principal
* `R` = Rate
* `T` = Time

### Input

Three numbers:

```text
P
R
T
```

### Output

Print the simple interest.

### Example

**Input:**

```text
10000
5
2
```

**Output:**

```text
1000
```

### What You Practice

* Multiple inputs
* Mathematical formulas
* Variables
* Arithmetic operators
